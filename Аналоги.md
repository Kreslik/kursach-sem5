# Аналоги системы «Заявки УК»

В сегменте ЖКХ/PropTech есть коммерческие решения с похожей функцией «заявки жителей → диспетчер → исполнитель».

| Система | Что близко к нашей системе | Чем отличается / избыточно |
|---|---|---|
| **Домиленд** | PropTech-платформа, которую используют крупные девелоперы и УК; личный кабинет жителя, приём и отслеживание заявок | Полноценная экосистема (оплата ЖКУ, бронирование сервисов, маркетплейс) — на порядок шире функционал |
| **Контур.ЖКХ** | Программа для ТСЖ и УК с ведением паспортного учёта и интеграцией с ГИС ЖКХ | Акцент на расчёт квартплаты и бухгалтерию, а не на диспетчеризацию заявок |
| **HubEx FSM** | Система для автоматизации сервисного обслуживания и управления мобильными сотрудниками: учёт заявок, GPS-контроль, SLA | Универсальный field-service инструмент для разных отраслей, а не только ЖКХ; избыточно сложен для трёх ролей ТЗ |
| **1С:Предприятие (отраслевые решения для УК)** | Платформа с прикладными решениями для автоматизации деятельности организаций, включая ЖКХ | Требует лицензии 1С и конфигурирования; не изначально веб-архитектура |
